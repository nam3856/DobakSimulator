소울 증폭에 도전하는 순서

  1. 소울을 사용할 무기를 선택하세요. 시뮬레이터는 요구 레벨 200 이상의 주무기를 대상으로 합니다. 직접 설정은 위대한 소울이 장착된 영구 무기를 전제로 합니다.
  2. 시작 증폭과 누적 실패를 확인하세요. 현재 무기에서 시작하거나 0~4단계를 직접 선택할 수 있습니다. API가 제공하지 않는 누적 실패 수는 0부터 시작하므로 필요하면 수정하세요.
  3. 목표 단계와 에테르 단가를 입력하세요. 목표는 최대 4단계입니다. 보유 재료를 별도 비용 없이 계산하려면 해당 단가를 0으로 입력할 수 있습니다.
  4. 증폭 시도 또는 자동 실행을 누르세요. 실패 시 다음 성공 확률이 올라가는 과정과 단계별 에테르 사용량, 누적 비용을 확인합니다.

에테르 가격도 총비용에 반영

기댓값·백분위·행운 판정은 강화 메소와 소비한 에테르의 입력 단가 환산액을 합산합니다. 단계별 에테르 수량도 별도로 기록하므로 재료 소비를 함께 볼 수 있습니다.

기본 에테르 단가는 1~4단계 순서로 15억·20억·12억·40억 메소입니다. 실시간 시세가 아닌 초기 입력값이므로 원하는 가격으로 변경하세요.

실패 누적을 함께 설정하는 이유

실패해도 증폭 단계는 유지되고, 같은 단계의 다음 시도 성공 확률이 증가합니다. 일정 실패 횟수 이후에는 성공이 보장되는 규칙을 반영합니다. 따라서 같은 시작 단계라도 누적 실패 수에 따라 남은 기댓값이 달라집니다.

기댓값은 지금 설정한 시작 상태에서 목표 단계까지 필요한 비용입니다. 이미 만든 소울의 과거 증폭 비용은 포함하지 않습니다. 0단계부터 만드는 비용을 비교하려면 시작 증폭과 누적 실패를 모두 0으로 맞추세요.

에테르 단가만 변경하면 진행 기록을 유지하면서 총비용과 분포를 다시 계산합니다. 목표나 시작 상태를 변경할 때는 새 조건을 확인하고 도전하세요.

증폭과 잠재능력은 어떻게 다른가요?

소울 증폭에서 잠재옵션도 재설정하나요?

이 모드는 증폭 단계에 도전합니다. 증폭 1~4단계에서 잠재옵션을 바꾸고 싶다면 소울 잠재 시뮬레이터 안내를 확인하세요. 잠재 재설정은 별도의 메소 비용을 사용합니다.

자동 실행을 중지해도 이어서 할 수 있나요?

자동 실행은 목표 단계까지 진행하며 중지 후 다시 실행할 수 있습니다. 완료 후 재도전하면 같은 시작 단계·실패 누적·목표에서 비용 0으로 다시 시작합니다.

에테르 단가를 0으로 입력하면 어떻게 되나요?

입력한 0을 유지하며 에테르 환산액을 더하지 않습니다. 소비한 에테르 개수와 강화에 사용한 메소는 계속 기록됩니다.

현재 단계에서 목표까지, 소울 증폭 비용을 체험하세요.

기본 캐릭터로 바로 체험하거나 내 캐릭터를 불러와 도전할 수 있습니다.
