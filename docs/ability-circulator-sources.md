# 어빌리티 고급 재설정·심연의 서큘레이터 자료

기준 업데이트는 KMS 2026-09-17이며, 2026-09-18에 공식 자료를 다시 조회했다. 최종 목표 세 종류가 모두 레전드리이고 각각 최댓값인 경우를 비교하기 위한 자료다. 세 종류의 최종 줄 순서는 제한하지 않는다.

## 확정된 사용 규칙

심연의 서큘레이터는 전체 어빌리티가 레전드리일 때 사용한다. 현재 세 줄의 등급과 종류를 유지하고 수치만 재설정한다. 결과 전체를 적용하거나 이전 전체 결과를 유지할 수 있다. 개별 수치는 상승·하락·유지가 가능하다. 모든 옵션에 바뀔 수 있는 수치가 없으면 사용할 수 없다. 1개 사용 시 별도 명성치나 메소 과금은 없고 아이템을 소비한다. 공식 판매가는 4,900캐시 또는 4,900크레딧이다. 이 가격은 경매장 메소 시세와 구분한다.

고급 재설정의 비용과 줄 등급은 기존 내장 자료를 그대로 사용한다.

| 잠근 줄 | 1회 명성치 |   1회 메소 | 명성치 5,000 환산 개수 |
| ------- | ---------: | ---------: | ---------------------: |
| 0       |     20,000 |  2,000,000 |                      4 |
| 1       |     30,000 |  6,000,000 |                      6 |
| 2       |     40,000 | 15,000,000 |                      8 |

첫 줄은 항상 레전드리이며, 둘째·셋째 줄은 각각 에픽 83%, 유니크 15%, 레전드리 2%다. 등급을 정한 뒤 고정된 종류와 먼저 나온 종류를 제외하고 종류 확률을 다시 정규화하며, 마지막으로 그 종류의 수치를 추첨한다. 3회 비교는 같은 시작 잠금 상태에서 세 번 모두 비용을 지불한다.

## 수치 분포 검증

심연의 서큘레이터에 별도의 최대값 보장이나 별도 수치 확률표는 없다. 공통 확률표의 여섯 행을 읽고 같은 표시 수치를 합산한다. 예를 들어 공격력의 레전드리 여섯 행은 27·27·27·30·30·30이므로 30의 확률은 15%+15%+10%=40%다.

| 레전드리 옵션             | 최댓값 | 한 줄 수치 추첨에서 최댓값 확률 |
| ------------------------- | -----: | ------------------------------: |
| 패시브 스킬 레벨          |      1 |                            100% |
| 재사용 대기시간 미적용    |    20% |                             10% |
| 상태 이상 대상 데미지     |    10% |                             60% |
| 보스 데미지               |    20% |                             10% |
| 크리티컬 확률             |    30% |                             10% |
| 공격력·마력               |     30 |                             40% |
| 버프 지속시간             |    50% |                             10% |
| 아이템 드롭률·메소 획득량 |    20% |                             25% |

레벨당 공격력·마력은 표시 숫자가 작을수록 좋으며, 10레벨당 1이 최선이다. 데이터는 이를 `valueDirection: lower`와 `bestValue`로 표현한다.

`scripts/sync-abyss-circulator.mjs`는 에픽 31개·유니크 36개·레전드리 41개 종류의 모든 수치를 원문에서 다시 파싱한다. 기존 `ability.json`의 각 값과 합산 확률이 1e-12 이내로 일치하는지 확인한다. 따라서 계산 엔진에서 기존 어빌리티 값 분포를 재사용해도 같은 분포다. 새 파일의 범위는 고급 재설정으로 얻을 수 있는 종류·등급이며, 레어 줄이나 더 이상 고급 재설정에서 등장하지 않는 과거 전용 종류까지 지원한다는 뜻은 아니다.

## 계산에 적용하는 해석

공식 자료는 옵션별 수치 확률을 제공한다. 계산기는 각 줄의 수치를 해당 분포로 독립 추첨하는 모델을 사용한다. 별도의 줄 사이 결합 분포는 공지하지 않는다.

공통 어빌리티 확률 고지의 완전 동일 결과 제외를 심연의 서큘레이터에도 적용한다. 같은 줄 등급·종류·표시 수치가 같은 순서로 세 줄 모두 반복되는 결과만 제외하며, 한두 줄의 기존 수치가 유지되는 결과는 허용한다. 이는 공통 고지의 적용 해석이며, 개별 수치를 반드시 바꾸는 방식은 아니다.

공식 서큘레이터 설명에는 특정 줄 수치만 잠그는 기능이 없다. 계산기는 세 줄의 등급·종류를 고정한 채 수치를 함께 재설정하며, 고급 재설정의 잠금을 서큘레이터 수치 잠금으로 사용하지 않는다. 보조 두 줄을 먼저 최대로 만드는 경로는 두 보조 수치가 동시에 완성된 전체 결과를 얻은 다음, 고급 재설정으로 돌아가 보조 두 줄을 잠그고 첫 줄을 노리는 순서다. 세 종류를 모두 확보한 뒤 서큘레이터를 사용하는 경로는 세 줄이 동시에 최댓값을 만족해야 한다. 단일 수치 옵션의 최댓값 확률은 1이다.

이전 결과를 계속 보관하는 고정 상태에서 목표 결과의 무조건부 확률을 `q`, 현재 세 줄과 완전히 같은 결과의 확률을 `r`이라 하면, 목표 미달 상태의 서큘레이터 1회 성공률은 `q / (1-r)`다. 두 보조 줄만 최대화하는 단계에서도 `r`에는 목표와 무관한 첫 줄의 수치가 포함된다. 이미 목표를 만족하면 추가 서큘레이터는 필요 없다.

시작 프리셋에 목표 세 종류를 모두 레전드리로 확보했고 한 줄 이상 수치가 미완성인 경우 `current-types-circulator` 경로로 별도 표시한다. 기존 `all-*` 일곱 획득 순서는 이 시작 상태에서 같은 동작이므로 한 행으로 합친다. 추가 고급 재설정·명성치·고정 메소는 0, 서큘레이터 기대 개수는 `(1-r)/q`이며 전체 비용은 이 값에 서큘레이터 단가를 곱한다. 고급 재설정의 1회/3회 설정은 서큘레이터 사용 개수에 영향을 주지 않는다. 최종 줄 순서는 무관하지만 세 종류가 중복 없이 모두 있어야 하며, 유니크 이하 줄을 서큘레이터로 레전드리로 올리는 경로는 제공하지 않는다. 이미 전부 최대인 경우는 기존 무료 완료 판정을 유지한다.

명성치 훈장 가격은 사용자가 지정한 **명성치 5,000당 메소** 환산 단위다. 특정 이름의 모든 명예 훈장이 5,000을 지급한다는 의미는 아니다. 해당 단가를 `H`, 심연의 서큘레이터 메소 단가를 `C`라 하면 고급 재설정의 환산 비용은 각각 `2,000,000 + 4H`, `6,000,000 + 6H`, `15,000,000 + 8H`이고, 서큘레이터는 1회 `C`다.

## 자료 재생성

```powershell
node scripts/sync-abyss-circulator.mjs
node scripts/sync-abyss-circulator.mjs --offline
```

첫 명령은 공식 원문을 다시 조회하고, 두 번째 명령은 보관한 원문으로 동일한 자료를 재생성한다. 기존 `ability.json` 및 기존 어빌리티 스냅샷은 수정하지 않는다.
