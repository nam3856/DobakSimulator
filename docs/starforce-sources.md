# 스타포스 규칙 출처

기준은 2026-09-17 한국 본서버, 확인일은 2026-09-18입니다. 일반 장비만 지원합니다. 확률은 공식 문서를 재구성한 값이며, 시도 비용 공식과 단계 보존 복구 메소는 **JIJAKBI에서 교차 검증한 beta 자료**입니다. 비용까지 공식 공개 표인 것처럼 표시하지 않습니다.

## 공식 규칙과 확률

- [현재 스타포스 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/412): 장비 레벨별 최대 별, 모든 일반 강화 단계의 하락 없음, 15~17성 파괴 방지, 12성 복구와 단계 보존 복구를 확인합니다.
- [2025-03-20 업데이트767](https://maplestory.nexon.com/News/Update/767): 30성 확장, 15~29성 성공·유지·파괴 표, 파괴 방지 추가 비용이 기본 비용의 200%로 증가한 내용, 21성 이하 파괴 확률 30% 감소 이벤트를 확인합니다. 하락 삭제 시점은 2025년 7월이 아니라 3월입니다.
- [2026-03-19 업데이트799](https://maplestory.nexon.com/News/Update/799): 스타캐치 삭제와 성공률 보너스 상시 적용, 파괴 직전 별을 보존하는 흔적(최대22), 복구 재료 수량을 확인합니다.
- [2024-02-15 공식 확률 검증](https://archive.maplestory.nexon.com/News/ProbabilityResult/MonthData/20240215): 이벤트 미적용·파괴 방지 없음·스타캐치 성공 표의 **설정 확률** 중 0~14성을 사용합니다. 실측 비율은 사용하지 않습니다.
- [스타캐치 배율 안내](https://maplestory.nexon.com/News/Notice/All/133192): 기존 성공률의 1.05배임을 확인합니다.
- [MVP 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/425), [PC방 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/444): MVP 3/5/10%, PC방 5%, 17성까지 적용 및 슈페리얼 제외를 확인합니다. 할인 중첩과 반올림 구현은 JIJAKBI 비용 모델에 속합니다.

15~29성은 2025년 기본 표에 상시 스타캐치 효과를 적용합니다. 기존 성공률을 `p`, 파괴율을 `d`라고 하면 `p′=1.05p`, `d′=d(1−p′)/(1−p)`, 유지는 `1−p′−d′`입니다. 기존 실패 중 파괴 비율을 유지하는 변환이며, 재구성한 30개 전이를 JIJAKBI의 독립 NEXON NOW 확률 스냅샷과 대조했습니다. 예를 들어 15→16은 성공31.5%, 파괴2.055%이고 29→30은 성공1.05%, 파괴19.79%입니다. 표시 반올림을 실제 추첨 확률로 쓰지 않습니다.

일반 장비는 하락이 없어 찬스타임이 발생하지 않습니다. 스타캐치 선택도 없으며, 내장 표에 이미 반영된 보너스를 다시 곱하지 않습니다. 슈페리얼은 별도 하락·파괴 규칙이며 확인된 별도 확률·비용 자료가 없어 이번 계산에서 제외합니다. 놀라운 장비 강화 주문서 적용 장비와 고정 별 장비도 일반 모델로 계산하지 않습니다.

## 복구와 비용의 한계

일반 파괴 흔적은 `min(파괴 직전 별, 22)`를 저장합니다. 12성 복구는 같은 장비1개, 추가 메소0입니다. 별 보존 복구는 흔적18성 이하1개,19~20성2개,21성3개,22성4개와 레벨·단계별 메소를 사용합니다.

비용은 `JIJAKBI/rules/starforce.json`의 `kms-starforce-2026-08-20-beta-costs`를 원본 그대로 스냅샷으로 보관했습니다. 해당 프로젝트가 2026-09-04 [starforce.gg 계산 결과](https://starforce.gg/ev)와 대조한 출처 지문도 별도로 보존합니다. 사이트 코드를 런타임에 사용하거나 이식하지 않습니다. 이번 작업에서 그 사이트에 대한 새로운 검증을 했다는 의미는 아닙니다.

강화 기본 비용은 `1000 + 레벨³ × (현재 별+1)^지수 / 단계별 분모`를100메소 단위로 반올림합니다. 0~9성의 지수는1, 이후는2.7이며 단계별 분모는 JSON에 기록되어 있습니다. 파괴 방지를 켜면 할인 전 기본 비용의2배를 추가합니다. 할인 적용 후 비용도100메소 단위로 반올림합니다. 이 계산과 전체 별 보존 복구 메소 표의 정확도 상태는 beta입니다.

별 보존 복구 메소는 기록이 있는130/135/140/145/150/160/200/250제만 포함합니다. 다른 레벨로 보간하거나 확장하지 않습니다. 130/135제는 최대20성이므로15~19성 흔적만 필요합니다. 일반 시도 비용 모델의 입력 범위는1~250이며, 특수 장비의 실제 최대 별과 복구 재료는 따로 확인해야 합니다.

원본 JIJAKBI의 아스트라·데스티니 특수 복구 설정도 출처와 함께 보존하지만 일반 장비와 같은 것으로 추정해서는 안 됩니다. 장비 유형을 확정할 수 없다면 일반 모델에서 제외하거나 수동 일반 장비 선택을 사용해야 합니다. 원본 샤이닝 묶음은 이벤트마다 효과가 달라 기본 이벤트 목록에서 제외했습니다. 이벤트 없음이 기본이며30%비용 할인/21성이하 파괴30%감소만 별도 옵션으로 보존합니다.

## 재생성과 검증

```sh
node scripts/sync-starforce.mjs
node scripts/sync-starforce.mjs --offline
npx vitest run tests/starforce-data.test.ts
```

원문 HTML7개, JIJAKBI 비용 참조와 교차검증 지문은 `public/rules/snapshots/starforce/`에 gzip으로 저장합니다. SHA-256은 압축 해제한 원문에 대해 계산하며 `public/rules/starforce.json`에 기록합니다. 새로 복제한 저장소에서도 오프라인 재생성이 가능합니다. 전체 확률 합, 경계 확률, 보너스 중복 적용 방지, 레벨 상한, 복구 재료 수량, beta 비용 출처 및 모든 스냅샷 해시를 테스트합니다.

## 캐릭터 스타포스 데이터

Nexon 장비 API의 실제 `starforce` 값만 0~30 정수로 보존합니다. 누락·잘못된 값은0으로 추정하거나 범위를 강제 보정하지 않고 미확인으로 둡니다. 이름/설명의 명시적 슈페리얼 표기는 `superiorEquipment`, `starforce_scroll_flag`의 사용/미사용 표기는 `extraordinaryStarforce`로 분리합니다. 이 두 필드의 부재는 확인되지 않았음을 뜻하며, 일반 강화 가능 장비임을 증명하지 않습니다.

기본 깽미니 스냅샷은 2026-09-18 05:01:48 KST에 API에서 조회한75개 프리셋 장비의 실제 스타포스를 이름·슬롯·레벨이 일치하는 항목에 보충했습니다. 다른 기존 데이터는 유지하며 별도 `starforceFetchedAt`을 기록합니다. 공용 서버와 개인 키 검색은 같은 정규화 함수를 사용합니다. 공용 서버는 응답 캐시 없이 매번 조회하므로 캐시 버전 변경은 필요 없지만 정규화 코드가 포함된 Worker 재배포가 필요합니다. 키와 원본 응답은 공개 파일에 포함하지 않습니다.
