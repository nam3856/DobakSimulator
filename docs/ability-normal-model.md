# 일반 어빌리티 재설정과 자원별 최적화

## 적용 범위

- 기존 시뮬레이터와 같이 레전드리 시작 상태를 다룬다. 일반 탭은 `#abilityNormal`, 고급 탭의 기존 `#ability` 주소는 유지한다.
- `abilityResetMode`가 없는 기존 저장 설정은 고급 재설정으로 해석한다.
- 일반 최적화는 레전드리 목표 1개와 유니크 목표 0~2개를 비교한다. 선택한 등급의 최상위 수치가 목표이며, 이미 충족한 상태는 추가 소모 없이 완료한다.
- 명성치와 미라클·블랙·카오스의 사용 개수는 독립적인 자원이다. 가격 입력, 메소 환산, 서로 다른 자원의 합산 순위는 제공하지 않는다. 심연의 서큘레이터는 일반 비교에 포함하지 않는다.

## 공식 규칙

2026-09-22 확인:

- [어빌리티 게임 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/392)
- [명성치 재설정 확률](https://maplestory.nexon.com/Guide/OtherProbability/ability/reputevalue)
- [미라클 서큘레이터 확률](https://maplestory.nexon.com/Guide/OtherProbability/ability/miraclecirculator)

일반 재설정은 잠금 0/1/2개에 명성치 8,000/11,000/16,000을 사용한다. 메소는 소모하지 않는다. 첫 줄은 레전드리이며 아래 두 줄은 각각 에픽 85%, 유니크 15%다. 등급을 정한 뒤 잠긴 종류 및 앞서 등장한 종류를 제외하고 종류별 확률을 다시 정규화한다. 실패를 포함해 새 결과가 즉시 적용되며 3회 비교는 없다. 아랫줄 레전드리는 일반 재설정에서 잠글 수 없다.

미라클은 전용 종류 확률표를 사용하며 각 등급의 최상위 수치를 보장한다. `public/rules/ability-miracle.json`은 명성치 종류 확률을 대신 사용하는 자료가 아니다.

아랫줄에 레전드리가 있는 시작 상태의 미라클 사용 조건은 현행 공식 자료에서 확인하지 못했다. 이 상태의 미라클 경로는 비교에서 제외하고 사유를 표시한다. 게임 자체의 사용 금지로 단정하지 않으며 이미 목표를 달성했다면 추가 소모 0 처리를 우선한다.

블랙과 카오스는 전체 어빌리티 등급이 유니크 이상일 때 사용 가능하다. 아랫줄 레전드리는 허용되지 않지만 아랫줄 에픽은 허용된다. 등급·종류를 유지하고 세 줄 수치를 함께 바꾼다. 블랙은 결과 선택 적용, 카오스는 즉시 적용이다. 변경 가능한 수치가 없는 상태에서 불필요한 아이템 사용을 계산하지 않는다.

## 기댓값 계산 범위

일반 최적화는 명시한 잠금·준비 정책을 비교하며 모든 가능한 전략의 전역 최적해를 보장하지 않는다. 일반 재설정 및 미라클 획득 단계는 직전과 완전히 같은 표시 결과를 제외하는 보정만 생략한 독립 추첨 근사다. 줄 등급, 종류 중복 제외, 잠금별 명성치, 준비 단계 및 목표 잠금은 반영한다. 결과 화면에도 근사임을 표시한다. 명성치 할인 이벤트는 적용하지 않는다.

명성치 전용은 목표 줄을 즉시 잠그는 정책과 아랫줄을 먼저 완성하는 정책을 비교한다. 유니크 목표가 있을 때 두 정책 중 명성치 사용량이 적은 행을 표시하며 아이템 전략과 합산 순위를 매기지 않는다.

고정 종류의 블랙·카오스 수치 단계는 동일 결과 제외와 결과 적용 방식 차이를 각각 반영한다. 목표 성공 확률을 `q`, 현재 표시 결과의 추첨 확률을 `r`, 실패 결과들의 확률을 `p_i`라고 할 때, 현재 미완성 상태에서 블랙은 `(1-r)/q`, 카오스는 `(1-sum(p_i^2))/q-r`을 사용한다. 준비 과정에서 획득한 수치 분포와 이미 완성된 경우도 함께 평균 낸다.

일반 시뮬레이터 통계는 명성치가 기준이다. 작은 결과 공간에서는 즉시 적용에 따른 평균을 정확히 계산한다. 큰 결과 공간의 평균 및 분포는 독립 추첨 근사이며, 정확 평균이 가능한 경우에도 분포·백분위·행운은 근사임을 안내한다. 기존 고급 재설정 계산 경로는 유지한다.

## 데이터 정정

일반 최적화 검증 중 기존 HP/MP 퍼센트 옵션이 고정 증가량 가족과 섞이는 파서 오류를 수정했다. 유니크 5~10%, 레전드리 15~20%로 명성치 및 심연 데이터를 재생성했으며 별도 회귀 테스트를 추가했다.
