# 소울 증폭 확률 검증

검증일: 2026-09-18. 내장 규칙 `kms-soul-2026-09-17 / official-v1`과 실제 도전에 사용하는 엔진을 확인했다. 공식 확률과 다른 성공률이나 비용 계산 오류는 발견하지 않았다. 확률 및 실행 코드는 변경하지 않았다.

## 공식 자료 대조

[공식 소울웨폰 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/416)의 **3. 소울 증폭**에 있는 성공 확률·메소 표와 실패 누적 표를 검증일에 다시 조회했다. [2026-09-17 본서버 업데이트](https://maplestory.nexon.com/News/Update/813)의 소울웨폰 개편 안내와도 일치한다.

| 목표 단계 | 최초 성공 확률 | 실패 1회당 증가 | 누적 실패 후 다음 시도 보장 | 1회 메소 |
| --------- | -------------: | --------------: | --------------------------: | -------: |
| 1단계     |             5% |             1%p |                        25회 |      5억 |
| 2단계     |             3% |           0.6%p |                        33회 |     10억 |
| 3단계     |             2% |           0.4%p |                        43회 |   17.5억 |
| 4단계     |           1.5% |           0.3%p |                        50회 |   27.5억 |

실패 누적은 성공한 뒤 초기화된다. 따라서 최악의 경우 각 단계에서 26·34·44·51회, 전체 155회에 성공한다. 초기 확률을 매번 그대로 적용하는 기하분포보다 평균 시도가 크게 줄어든다.

## 실행 및 계산 검사

`tests/soul-amplification.test.ts`는 다음을 검증한다.

- 공식 값을 정수 확률 단위로 별도 입력해 내장 자료와 대조한다.
- 네 단계의 모든 실패 상태에서 성공 확률의 바로 아래·바로 위 난수로 실제 `rollBatch` 성공/실패 경계를 확인한다.
- 실패 누적, 보장 직전과 보장 시도, 성공 후 초기화, 시도마다 해당 단계 에테르 1개 및 메소 과금을 확인한다.
- 항상 실패하는 난수를 넣어 155회·264,250,000,000메소·에테르 26/34/44/51개라는 최악 경로를 확인한다.
- 모든 시작 단계·누적 실패에 대해 독립적으로 작성한 유한 성공 분포의 평균과 기댓값 계산기를 대조한다.
- 난수 변환의 양 끝 입력이 모두 0보다 크고 1보다 작은 값이 되는지 검사한다.

일반 실행과 Web Worker의 자동 실행은 모두 같은 `rollBatch`를 호출한다. 소울 증폭은 시도마다 난수를 한 번 뽑고, `난수 < 현재 성공 확률`로 판정한다. 비교 후보 중 좋은 결과를 고르는 로직이나 3회 재설정은 적용하지 않는다. 브라우저 도전은 `crypto.getRandomValues`를 사용하며, 고정 시드 난수는 아래 재현 가능한 검증에만 사용했다. 화면의 다음 성공 확률도 같은 단계·누적 실패 규칙을 따른다.

## 실제 도전 100만 회 비교

시작 0단계·누적 실패 0에서 목표 4단계까지, 실제 도전 엔진의 모든 유료 시도를 실행했다. 시드는 `soul-amplification-audit-2026-09-18`이다. 에테르 시장 가격은 포함하지 않는다.

| 비교                         |      독립 계산 | 실제 엔진 1,000,000회 평균 |
| ---------------------------- | -------------: | -------------------------: |
| 1단계 도달 시도              |       9.178244 |                   9.174358 |
| 2단계 도달 시도              |      12.624290 |                  12.615135 |
| 3단계 도달 시도              |      16.135231 |                  16.109119 |
| 4단계 도달 시도              |      19.110570 |                  19.107420 |
| 전체 메소                    | 98,004,135,592 |             97,938,677,250 |
| 평균 비용 이하로 완료할 확률 |       53.4595% |                   53.5106% |

전체 평균 비용 차이는 **−0.0668%**였다. 평균 비용의 표준오차는 35,843,571메소이며, 관측 차이는 약 1.83표준오차로 표본 변동 범위 안에 있다. 처음 한 번에 성공한 비율도 각 단계에서 5.0156%·2.9903%·1.9999%·1.4822%로 공식 초기 확률과 일치하는 범위였다.

해석적으로 계산한 0→4단계 비용의 P10은 537.5억, 중앙값은 950억, P90은 1,467.5억 메소다. 전체 평균은 약 980.04억 메소다. 평균보다 적게 쓰는 도전이 약 53.46%인 분포이므로 몇 번의 체험만으로 확률이 높다고 판단하기는 어렵다.

별도로 실제 `cryptoRandom`에서 100만 개를 추출한 점검에서는 평균 난수가 0.500166이었다. 5%·3%·2%·1.5% 임계값 아래에 든 비율은 5.0019%·2.9967%·1.9977%·1.4911%였다. 이는 구현에 뚜렷한 편향이 없는지 확인하는 표본 검사이며 게임 서버의 비공개 난수 구현까지 검증한 것은 아니다.

## 재현

일반 회귀 테스트는 1만 회 전체 도전을 실행한다. 상세 100만 회 검증은 PowerShell에서 아래와 같이 실행한다.

```powershell
$env:SOUL_AUDIT_TRIALS = '1000000'
npm.cmd test -- tests/soul-amplification.test.ts
Remove-Item Env:SOUL_AUDIT_TRIALS
Get-Content -Encoding UTF8 .cache/soul-amplification-audit.json
```

상세 실행 결과는 Git에서 제외한 `.cache/soul-amplification-audit.json`에 저장한다. 일반 테스트는 파일을 생성하지 않는다. 검증 시 8개 테스트가 모두 통과했다.
