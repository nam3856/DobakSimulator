- [추가옵션 게임 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/411): 적용 장비 범위 및 검은 환생의 불꽃의 기존/새 옵션 선택 기능.

| 수단                    | 일반 1/2/3/4/5단계 확률 | 보스 장비 단계 |
| ----------------------- | ----------------------- | -------------- |
| 메소 / 검은 환생의 불꽃 | 0 / 29 / 45 / 25 / 1%   | 4~7            |

## 옵션 수치 모델과 제한

공식 확률표는 모든 옵션의 수치 공식을 공개하지 않는다. 아래는 일반 장비에 적용하는 계산 모델이며, 전체 수치가 공식 문서에서 검증되었다고 표현하지 않는다. 위 보상 안내의 200제 스탯/공격력 예시는 회귀 테스트로 확인한다. 무기 수치는 기본 옵션의 공격력/마력을 사용하며 스타포스·주문서·기존 추가옵션을 포함한 합산 공격력을 사용하면 안 된다.

`L`은 레벨 감소 적용 전 요구 레벨, `t`는 최종 단계, `A`는 기본 공격력 또는 마력이다.

| 옵션                               | 구현 모델                                                                       |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| 단일 스탯                          | `(floor(L / 20) + 1) × t`, 단 250제 방어구는 관측값에 따라 `12 × t`             |
| 방어력                             | `(floor(L / 20) + 1) × t`, 단 250제 방어구는 관측값에 따라 `12 × t`             |
| 이중 스탯                          | 각 스탯에 `(floor(L / 40) + 1) × t`                                             |
| HP, MP                             | `3 × L × t`, 단 250제 방어구는 관측값에 따라 `700 × t`                          |
| 비무기 공격력/마력                 | `t`                                                                             |
| 무기 공격력/마력                   | `ceil(A × (floor(L / 40) + 1) × t × 1.1^(t - b) / 100)`, 보스 `b=3`, 일반 `b=1` |
| 올스탯%, 데미지%, 이동속도, 점프력 | `t`                                                                             |
| 보스 데미지%                       | `2 × t`                                                                         |
| 착용 레벨 감소                     | `5 × t`                                                                         |

### 250제 방어구의 API 실측 보정

2026-09-19 확인한 [넥슨 Open API 장착 장비](https://openapi.nexon.com/game/maplestory/?id=14) 기반 `public/character/snapshot.json`의 서로 다른 에테르넬 방어구 네 개는 단일 스탯 계수 13으로 재현되지 않으며, 계수 12와 이중 스탯 계수 7로 모두 재현된다. 아래는 API 합산값에서 복원한 해석이다. 이는 API 실측에 근거한 모델 보정이며 넥슨이 수치 공식을 발표한 것으로 표현하지 않는다.

| 장비                  | API 추가옵션                  | 복원한 네 옵션                                            |
| --------------------- | ----------------------------- | --------------------------------------------------------- |
| 에테르넬 파이렛햇     | STR42, DEX132, INT42, 올스탯4 | DEX48(4단계), STR+DEX42(6단계), DEX+INT42(6단계), 올스탯4 |
| 에테르넬 파이렛코트   | DEX125, INT35, LUK42, 올스탯5 | DEX48(4단계), DEX+INT35(5단계), DEX+LUK42(6단계), 올스탯5 |
| 에테르넬 파이렛팬츠   | STR42, DEX125, LUK35, 올스탯4 | DEX48(4단계), STR+DEX42(6단계), DEX+LUK35(5단계), 올스탯4 |
| 에테르넬 파이렛글러브 | STR28, DEX130, INT42, 올스탯5 | DEX60(5단계), STR+DEX28(4단계), DEX+INT42(6단계), 올스탯5 |

이 네 사례는 200제 수치로의 일괄 상한과도 맞지 않는다. 추가로 2026-09-19 13:09 UTC에 공개 캐릭터의 공식 API 장비를 확인하여 250제 에테르넬 나이트아머/팬츠의 HP4200·4900, 나이트아머의 MP4200, 나이트글러브의 방어력72를 교차 확인했다. HP/MP는 단계당700, 방어력은 단계당12로 재현된다. 재검토할 수 있는 비밀정보 없는 원본 수치와 조회시각은 `tests/fixtures/bonus-options-250-api.json`에 보관한다. 테스트는 각 장비의 네 옵션을 모두 복원하고 현재 옵션 배제 확률까지 검산한다.

보정은 확인된 **250제 방어구**에만 적용한다. 이 사례를 250제 무기나 다른 고레벨 구간의 실측 증거로 사용하지 않는다.

특수 장비의 수치 규칙을 자동 추론하지 않는다. 제로의 성장·전승 무기, 해방 단계별 제한, 고정 단계 장비, 보스 아레나 엠블렘과 같은 예외는 일반 장비로 임의 판단하면 안 된다. 엔진에는 확인된 고정 단계를 지정하는 `fixedTier` 입력만 있으며, 이름으로 예외 단계를 추측하지 않는다. 일반 API의 장비 종류·레벨만으로 보스 장비 여부가 확정되는 것도 아니다.

점수는 사용자가 정한 각 스탯의 환산 비율을 곱한 합이다. 기본값은 주스탯 1, 공격력/마력 3, 올스탯 10이다. 이는 비교용 점수이고 캐릭터의 실제 전투력 증가율이나 최적 딜 계산이 아니다. 제논·데몬어벤져 등은 자신의 기준에 맞게 복수 스탯/HP 비율을 직접 설정할 수 있다. 환생의 불꽃 가격은 사용자 입력이며, 0은 아이템 소비가 없다는 뜻이 아니라 메소 환산액을 0으로 설정한 것이다.

## 매회 적용 방식과 근사 기댓값

화면은 수동·자동 진행 모두 매 시도의 새 추가옵션을 즉시 적용한다. 목표를 달성하면 멈추고 다시 진행할 수 있다. 실제 추첨은 현재 옵션과 합산 수치가 같으면 무료로 다시 추첨하며, 비교 대상은 매번 새로 적용된 옵션으로 바뀐다.

`evaluateBonusReroll`은 모든 옵션 조합과 단계 배정을 열거해 목표 점수 이상일 기본 확률 `p`를 계산한다. 표시하는 기댓횟수 `1/p`, 기댓비용, 중앙값, 90% 도달 횟수와 행운은 이 기본 확률이 매회 일정하다고 보는 **독립 시행 근사값**이다. 현재 옵션 배제로 인한 작은 확률 변화를 누적 계산하지 않으므로 실제 매회 적용 전략의 정확한 도달 분포로 표현하지 않는다. 반환값의 `method`는 `independent-baseline`이며 `successProbability`는 `baseProbability`와 같다. 이 비교 모델이 생략한 현재 옵션 보정량인 `excludedProbability`는 0이다.

기존 분석 함수 `evaluateBonusOptions`는 같은 시작 옵션을 목표까지 보존하는 전략을 별도로 검증하기 위해 유지한다. 현재 합산 수치가 나오는 모든 배정의 확률 `q`를 합산하며, 목표 미달 옵션을 고정 보존하면 다음 성공 확률은 `p / (1 - q)`이다. 이 함수의 조건부 기하분포 결과를 매회 새 옵션을 적용하는 화면의 정확한 기댓값으로 사용하지 않는다. 같은 수치가 여러 이중 스탯 조합으로 만들어질 수 있어 배정 하나만 역산해서 현재 결과를 배제하지 않는다.

이미 목표를 달성한 현재 옵션에는 남은 기댓횟수/비용 0을 반환한다. 불가능한 목표는 확률 0, 기댓횟수/비용 무한대로 표시한다. `previous`를 생략하면 현재 옵션 미상으로 보고 기본 확률을 쓴다. `previous`의 생략된 개별 스탯은 0으로 해석하므로 실제로 확인되지 않은 데이터를 0으로 채워 확정된 현재 옵션처럼 전달하지 않는다.

기본 확률 계산은 몬테카를로 추정이 아닌 수치 모델의 전체 경우의 수 합산이다. **모델 안의 정확한 기본 확률**, **매회 적용 전략의 근사 도달 분포**, **모든 장비에서 공식 확인된 수치 규칙**은 구분해야 한다. 운 지표는 독립 시행 모델에서 N회 이내 목표에 도달할 누적 확률이며, 이미 많은 시도를 했다고 다음 성공 확률이 올라가는 보정은 없다.
